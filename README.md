# Idle-Eden

A little garden that keeps growing even when you close the tab.

**Demo:** https://ghost8911.github.io/Idle-Eden/

## How it grows

The garden doesn't store its size. It stores when it was planted and when you last watered it, then works everything out from the clock each time the page loads. So it keeps growing while you're away.

- Stages: seed, sprout, plant, tree (with a flower)
- Forget to water it and it wilts
- Every garden gets a random colour mutation
- A growth log records when each stage was reached

Made for Hack Club Crescent, theme "Growth". Plain HTML, CSS and JavaScript.
